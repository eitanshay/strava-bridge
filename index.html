Hard Sets → Strava

A one-file bridge: it holds your own Strava API app credentials in this browser and creates Weight Training activities with the workout details Hard Sets hands it in the link.

1 · Strava API app

  1. Open strava.com/settings/api and create an app (any name, category "Training").
  2. Set Authorization Callback Domain to this page's host:
  3. Paste the Client ID and Client Secret below. They never leave this browser.

3 · Push this workout
